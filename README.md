# 🪐 پلتفرم مدیریت و برنامه‌ریزی رویداد آموزشی (LMS EventPlanet)

این پروژه یک سامانه کاملاً **API-First** جهت برنامه‌ریزی و مدیریت دوره‌های آموزشی است که با فریم‌ورک **Django** و **Django REST Framework (DRF)** پیاده‌سازی شده و از دیتابیس پایدار **PostgreSQL** استفاده می‌کند. پروژه به طور کامل داکریزه شده و دارای یک رابط کاربری سبک اختیاری و پویا است.

---

## 📐 تصمیمات معماری و فرضیات مهندسی (Architectural Decisions)

طبق نیازمندی‌های داک پروژه، تصمیمات کلیدی زیر اتخاذ و در منطق سیستم اعمال شده‌اند:
1. **ثبت‌نام برای کل رویداد یا مرحله؟** ثبت‌نام به صورت کلی برای کل رویداد/دوره انجام می‌شود و شرکت‌کننده با یک بار پرداخت موفق آنلاین، به تمام مراحل و سرفصل‌های چندگانه آن دوره دسترسی خواهد داشت.
2. **ظرفیت برای هر مرحله است یا کل رویداد؟** ظرفیت (`capacity`) به صورت متمرکز متعلق به کل رویداد است. با هر ثبت‌نام، یک واحد از ظرفیت کل دوره کم شده و پس از اتمام ظرفیت، امکان ثبت‌نام مجدد بسته می‌شود.
3. **معماری ویژگی‌های داینامیک:** سیستم از الگوی طراحی **EAV (Entity-Attribute-Value)** بدون ستون‌های اضافه یا استفاده از `JSONField` استفاده می‌کند که انعطاف‌پذیری ۱۰۰٪ Type-safe را فراهم می‌سازد.
